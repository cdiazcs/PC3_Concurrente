# Cliente Android — integrante 3

**No implementado aún.** Crear desde Android Studio un proyecto **Empty Views Activity** en Kotlin. Implementar chat de imagen/resultado; usar `Socket`/`DataOutputStream` del SDK (sin Retrofit/OkHttp/WebSocket), trabajo de red fuera del hilo principal, `idSolicitud`, control de timeout y selector de imagen. Respetar contrato acordado `contracts/`.

Para servidor remoto en LAN, añadir `INTERNET` al `AndroidManifest.xml`, configurar host/puerto por usuario y jamás usar `localhost` para referirse al PC desde Android.
